# Asset Permission Record

## Purpose

This document records permission to reuse material from **WarFighter Modification - Total Overhaul** in the Gates of WarFighter asset lab and downstream Gates of Hell mod work.

## Recorded permission

- **Source project:** WarFighter Modification - Total Overhaul
- **Permission grantor:** Yuri, identified by the project owner as the primary WarFighter developer
- **Permission recipient:** project owner
- **Record date:** 2026-08-09
- **Permission confirmed:** express approval to use the complete WarFighter mod and all content included with it
- **Included content:** models, textures, materials, normal maps, animations, rigs, sounds, music, voice work, maps, scripts, configuration, localization, UI, logos, branding, and supporting files included with WarFighter
- **Approved work:** porting, modifying, integrating, testing, and redistributing WarFighter content in the Gates of WarFighter asset lab and downstream Gates of Hell mod projects

## Current project use

Gates of WarFighter is now the import and validation laboratory for WarFighter content.

Assets are converted and tested individually in Gates of Hell, then may be handed off to the downstream **Gates of Code:4X** project for integration into a Code:X-based submod.

This permission record applies to WarFighter content. It does not grant permission to copy or redistribute Code:X. Code:X remains external to this repository and is used downstream under the Code:X submod relationship.

## Scope

Yuri's approval covers the complete WarFighter content library used by this project. No WarFighter asset category requires a separate project permission gate before technical import.

The project must still preserve provenance and attribution. Permission to use the content does not transfer ownership, erase original authorship, or permit project contributors to claim upstream work as their own.

## Evidence record

The original permission conversation should be preserved outside the public repository. A redacted or Yuri-approved copy may be added under `docs/permission-evidence/` when appropriate.

The evidence record should capture:

1. Yuri's account identity or other reliable identifier
2. the date and platform of the conversation
3. the exact permission language
4. any requested credit wording
5. any distribution or presentation conditions Yuri specified

Do not publish private messages, personal information, or screenshots without the participants' consent.

## Asset acceptance rule

WarFighter-derived files may enter the project through approved implementation slices. Each manifest entry must record:

- source path and source version
- V1/V2 source selection
- asset type
- original author or best-known contributor where identifiable
- permission basis: complete WarFighter approval from Yuri
- required attribution
- dependencies
- conversion/reconstruction steps
- destination path
- input and output hashes
- editor/native validation status
- reviewer and acceptance status

The manifest exists for technical provenance, reproducibility, dependency completeness, and credit. It is not an asset-by-asset reauthorization process.
